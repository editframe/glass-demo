// edge distance → height → normal
float d = texture(uSdf, uv).r;
float h = bevel(d);

// bend the scene along the normal

vec3 col = texture(uScene, bent).rgb;
col += fresnel(n) + specular(n);
So how does it work? Three layers.
At the bottom, an ef-video element. Or any HTML at all.
In the middle, ef-surface mirrors those pixels onto a canvas, every single frame.
On top, a WebGL shader samples that canvas, and bends each pixel along the glass's surface normal.

without
// nine wavelengths, each with its own IOR
for (int i = 0; i < 9; i++) {
  float t = float(i) / 8.0;
  float k = 1.0 + uDispersion * (t - 0.5);
  col += sample(px - n.xy * uRefract * k) * spectrum(t);
}
Red, green and blue bend by slightly different amounts. That's the rainbow edge.
